为什么选这个场景

Why This Scenario

它不需要大数据，也不需要复杂评测；只要看 JSON 是否有效、字段是否齐全、枚举和日期是否正确，就能判断模型行为是否被推向目标。

It does not need a large dataset or a complex benchmark. Valid JSON, complete fields, constrained enum values, and correct date extraction are enough to judge whether the model behavior moved in the right direction.

目标清晰

输入是一句话需求，输出是固定任务卡 JSON。

反馈直接

字段、枚举、日期、owner 都可以直接检查。

适合小模型

Qwen3-0.6B 加 LoRA 就能完成学习闭环。

Clear Target

Input is one task request. Output is a fixed JSON task card.

Direct Feedback

Fields, enum values, dates, and owner extraction are easy to inspect.

Small-Model Friendly

Qwen3-0.6B with LoRA is enough to complete the learning loop.

当前结果

Current Result

同步 data 和 prompts 的 system prompt 后，使用 `--mask-prompt` 训练 100 step，当前结果如下。它已经完成最小学习目标，但还不是产品级模型。

After synchronizing the dataset system prompt with `prompts/system.txt`, the adapter was trained for 100 iterations with `--mask-prompt`. This completes the learning goal, but it is not a production model.

34samples / 样本总数
0.240test loss
1.272test ppl
2.884Mtrainable LoRA params

关键学习点：240 step 在小数据上过拟合；补边界样本并使用 100 step 更稳。下一轮应继续补数据，而不是继续加训练步数。

Key lesson: 240 iterations overfit this tiny dataset. Adding boundary samples and training for 100 iterations was more stable. The next improvement should be more data, not simply more steps.
